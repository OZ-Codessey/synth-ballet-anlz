아래 필터(기간·훈련 상황·지표)를 바꾸면 ①~③ 차트가 실시간으로 다시 그려집니다. ④~⑥은 부상 시점이 고정된 사건이므로 필터와 무관하게 항상 전체 기간 기준으로 표시됩니다.

  1. 지표 트렌드 + 7일 이동평균 — 선택한 지표(기본: 그랑 제떼)의 일별 값과, 노이즈를 줄인 7일 이동평균선을 함께 표시합니다. 최근 흐름 파악용.
  2. 요일별 연습시간 vs 피로도 — 요일마다 평균 연습량과 피로도가 어떻게 다른지 비교합니다.
  3. 지표 간 상관관계 히트맵 — 7개 지표가 서로 얼마나 관련 있는지 -1~+1 숫자로 표시합니다.
  4. 부상 전/중/회복 단계별 비교 — 2025-08-18 발목 부상을 기준으로, 3개 기술지표가 단계별로 얼마나 변했는지 "부상 전=100" 기준 지수로 비교합니다(단위가 달라 원본값 비교가 왜곡되는 것을 막기 위함).
  5. 훈련부하(AU)와 부상 전조 추적 — 훈련부하와 피로도·통증이 부상 시점 전후로 어떻게 움직였는지 표시합니다.
  6. 예측 모델 신뢰도 — 훈련부하·컨디션 정보로 각 지표를 얼마나 정확히 예측할 수 있는지 지표별로 비교합니다.

사용 안내

  • ① ⑤ 클릭 — 원하는 지점을 클릭하면 해당 날짜의 상세 기록(메모 포함)이 팝업으로 표시됩니다.
  • ① ⑤ 호버 — 마우스를 올리면 세로 점선(지시선)으로 현재 위치가 표시되고 해당 지점이 확대되며, 데이터 포인트가 바뀔 때마다 피아노 음색의 알림음이 재생됩니다. 마우스가 그래프를 벗어나면 지시선은 사라집니다.
  • ① ⑤ 방향키·Enter — 그래프를 클릭해 포커스를 준 뒤 ←→로 데이터 포인트를 한 칸씩 정밀 이동할 수 있고, Enter로 해당 날짜의 팝업을 열거나(열려있으면) 닫을 수 있습니다.
  • ① ⑤ 확대(🔍) — 번호를 클릭하면 화면 대부분을 채우는 큰 모달로 확대되며, 이 상태에서도 클릭·호버·방향키·Enter가 동일하게 작동합니다. 모바일 세로 화면에서는 확대 시 자동으로 가로모드처럼 회전되어 표시됩니다.
  • ① 참고선 — 선택한 구간의 평균값을 점선 기준선(범례에 실제 수치 표시)으로 함께 보여줍니다. y축은 0이 아니라 실제 값 근처에서 시작해 변화폭이 더 잘 보이도록 설계했습니다.
  • ① 요약 박스 — 우측 상단 박스플롯에서 선택 구간의 최소·Q1·중앙값·Q3·최대·평균·이상치를 한눈에 확인할 수 있습니다.
  • 날짜 입력창 — 옆의 ‹› 버튼 또는 입력창에 포커스한 뒤 ←→ 방향키로 간편하게 하루씩 조정할 수 있습니다.
  • 훈련 상황(event_type) 필터 — 클릭 시 선택 상태가 전환되며 각 동작이 서로 다른 음으로 확인됩니다.
  • ③ 히트맵 호버 — 셀에 마우스를 올리면(또는 터치하면) 즉시 두 변수의 원어 이름과 상관계수가 말풍선으로 표시됩니다.
  • ③ 히트맵 클릭 — 셀을 클릭하면 아래에 Pearson 상관계수 계산식과 강도·방향 해석, 관련 인사이트가 표시됩니다. 마우스가 표를 벗어나면 자동으로 닫힙니다.
  • 모바일·태블릿 — 손가락을 대는 즉시(떼지 않아도) 호버와 동일한 반응이 나타나며, 탭하면 클릭과 동일하게 작동합니다. 모든 차트·표·글자 크기는 화면 폭에 맞춰 자동으로 조정됩니다.
  • 모든 소리는 외부 음원 없이 코드로 직접 합성한 피아노 음색이며, 클릭·호버·확대마다 서로 다른 음높이를 사용해 어떤 동작인지 소리로도 구분됩니다.
  • ① ⑤ 날짜 동그라미 표시 — 지시선이 움직일 때 그 지점의 실제 데이터 포인트(색 동그라미) 바로 옆에 요일·날짜(예: Fri 9/25)가 작은 글자로 함께 표시되어, 클릭 전에 어떤 날짜인지 미리 확인할 수 있습니다.
  • 모바일 터치 — 탭하면 그 지점의 지시선·날짜가 표시되고 다시 탭하면 상세정보가 열립니다. 스크롤·핀치줌은 항상 기기 기본 동작으로 정상 작동합니다.
  • ①⑤ 확대(🔍) 모달 — 화면 대부분을 채우는 크기로 확대되며, 모바일 세로 화면에서는 가로모드처럼 자동 회전됩니다. 회전 중에도 지시선·날짜·툴팁이 정상 작동하며, 스크롤로 넘치는 부분을 모두 볼 수 있습니다.
  • 반응형 디자인 — 모든 차트·표·글자 크기가 화면 폭에 맞춰 자동 조정되며, 화면을 넓게 볼수록 부드럽게 커집니다.

용어 — AU(훈련부하): 연습시간(분)×RPE로 계산한 하루치 훈련 부담량. RPE(운동자각도): 본인이 느끼기에 얼마나 힘들었는지 0~10점으로 매긴 점수. ACWR(급성:만성 부하비율): 최근 7일 훈련량 ÷ 최근 4주 평균 한 주 훈련량. 1.5를 넘으면 과부하 위험 신호로 본다. R²(결정계수): 1 − (모델 오차제곱합 ÷ 평균값 예측 오차제곱합). 모델이 평균값 예측보다 오차를 얼마나 줄였는지를 0~1로 나타낸 값(1=완벽, 0=개선 없음).

대시보드 요약 — 필터→①~③ 실시간 반영 · ①⑤ 그래프: 탭/클릭=날짜상세, 호버·드래그=지시선(동그라미 옆 날짜 표시), Enter=팝업, 번호 옆 🔍=확대(모바일 가로모드 자동전환) · 히트맵: 호버=원어명+수치, 클릭=계산식 · 모든 화면 크기·핀치줌에 반응형. 전체 목록은 위 "자세히 보기" 참고.
